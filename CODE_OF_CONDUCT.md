# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and welcoming experience for everyone.

## Expected Behaviour

All contributors are expected to:

* Be respectful and considerate.
* Communicate politely.
* Accept constructive feedback.
* Respect different opinions and experiences.
* Focus on improving the project collaboratively.

## Unacceptable Behaviour

The following behaviour is not acceptable:

* Harassment or discrimination.
* Insulting or threatening language.
* Personal attacks.
* Sharing private information without permission.
* Disruptive or disrespectful communication.

## Reporting Issues

If you experience or observe unacceptable behaviour, please report it to the repository owner through GitHub.

GitHub repository: git clone https://github.com/Prakruthi-6924/EL10-11-VCS.git

## Responsibilities

The repository owner is responsible for reviewing reported concerns and taking appropriate action to maintain a respectful environment.

## Scope

This Code of Conduct applies to all project-related activities, including discussions, issues, pull requests, and contributions.

## Acknowledgement

All contributors are expected to follow these guidelines and help maintain a friendly and inclusive project community.
